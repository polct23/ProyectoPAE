RACC Mobility Ontology

Ontologia de Mobilitat RACC

Descripció

Aquesta ontologia modela incidents de trànsit, segments de carretera i esdeveniments de mobilitat basada en dades del RACC (Reial Automòbil Club de Catalunya).

L'ontologia estén SOSA/SSN per a observacions d'incidents de trànsit i integra GeoSPARQL per a dades espacials i QUDT per a mesures.

Descàrregues

Formats disponibles:

📥 Descarregar Turtle .ttl 📥 Descarregar JSON-LD Context .jsonld

Nota: El fitxer raccmobilityontology.ttl conté l'ontologia completa en format Turtle (RDF). El fitxer racc-context.jsonld conté el context JSON-LD per facilitar la integració amb aplicacions basades en JSON.

Ús amb JSON-LD

Per utilitzar el context JSON-LD en els teus documents, afegeix aquesta referència:

{
  "@context": "https://<el-teu-usuari>.github.io/<el-teu-repo>/racc-context.jsonld",
  ...
}

Classes principals

  • racc:TrafficIncident - Incident de trànsit (accidents, retencions, obres, avaries)
  • racc:Road - Carretera o via de transport
  • racc:RoadSegment - Segment específic d'una carretera
  • racc:Municipality - Municipi o àrea administrativa
  • racc:Province - Província

Ontologies relacionades

  • SOSA/SSN - Sensor, Observation, Sample, and Actuator ontology
  • GeoSPARQL - Geographic data representation
  • QUDT - Quantities, Units, Dimensions and Data Types
